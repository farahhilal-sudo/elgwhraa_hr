# نظام الحضور والموارد البشرية (نسخة PostgreSQL)

موقع يشتغل كتطبيق على الموبايل (PWA): حضور وانصراف ببصمة الوجه + الموقع، طلبات، خصومات ومرتبات، وصلاحيات يحددها المدير.

البيانات بتتحفظ في قاعدة **PostgreSQL** خارجية (مثلاً Neon المجانية)، يعني السيرفر ممكن يتعمله إعادة تشغيل أو ينام والبيانات تفضل موجودة.

## متغيرات البيئة

| المتغير | المعنى |
|---|---|
| `DATABASE_URL` | **مطلوب.** رابط قاعدة PostgreSQL (من Neon أو غيره) |
| `ADMIN_PASSWORD` | كلمة مرور المدير في أول تشغيل (لو مش محددة: `admin123` وهيطلب تغييرها) |
| `JWT_SECRET` | نص عشوائي طويل (اختياري؛ لو مش موجود بيتولّد ويتحفظ في القاعدة) |
| `PORT` | بتحدده الاستضافة تلقائياً |

## تجربة على الكمبيوتر

المطلوب: Node.js 18 أو أحدث، وقاعدة PostgreSQL (ممكن قاعدة Neon تجريبية).

```bash
npm install
export DATABASE_URL="postgresql://user:pass@host/dbname?sslmode=require"
npm start            # افتحي http://localhost:3000
npm run seed         # اختياري: موظفين تجريبيين (كلمة المرور 123456) — على قاعدة تجريبية فقط
```

أول دخول: المستخدم `admin` وكلمة المرور `admin123` (أو `ADMIN_PASSWORD`).

> الكاميرا وGPS في المتصفح بتشتغل بس على `https://` أو `localhost`. الاستضافات (Render وغيرها) بتدّي https تلقائياً.

## النشر

Render (Web Service مجاني) + Neon (قاعدة مجانية):
- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/healthz`
- أضيفي `DATABASE_URL` و`ADMIN_PASSWORD` في Environment.

## ملاحظات

- مسار `/healthz` بيرد `ok` من غير ما يلمس القاعدة، وينفع لأدوات "إبقاء السيرفر صاحي".
- بصمة الوجه هنا مطابقة وجه بالكاميرا (face-api) وليست بصمة بيومترية؛ مفيهاش كشف حياة كامل.
- الموقع بييجي من المتصفح ويمكن التلاعب به بتطبيقات تزييف الموقع.
- النسخ الاحتياطي: Neon بتحتفظ بسجل تغييرات لفترة قصيرة في الخطة المجانية، فخدي نسخة دورية بـ `pg_dump` لو البيانات مهمة.
