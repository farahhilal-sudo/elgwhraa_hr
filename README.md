# نظام الحضور والموارد البشرية (PostgreSQL)

موقع يشتغل كتطبيق على الموبايل (PWA): حضور وانصراف ببصمة الوجه + الموقع، طلبات، مرتبات، وصلاحيات يحددها المدير.
البيانات بتتحفظ في قاعدة **PostgreSQL** خارجية (Neon)، فالسيرفر ممكن يتعمله إعادة تشغيل والبيانات تفضل موجودة.

## المميزات
- تسجيل بصمة الوجه مرة واحدة لكل موظف من موبايله، وتسجيل حضور وانصراف يومي بالوجه والموقع.
- **شرائح خصم التأخير:** صفحة يحدد فيها المدير خصم كل شريحة تأخير (جزء من أجر اليوم أو مبلغ ثابت).
- **المكافآت والجزاءات والخصومات:** صفحة لإضافة البنود، وبتتحسب تلقائياً في المرتب.
- المرتبات، الطلبات والإجازات، التقارير، الصلاحيات.
- **الشكل:** على الشاشات الكبيرة (ويب): شريط علوي (بحث عن موظف، التاريخ والساعة، الإشعارات، قائمة المستخدم) وقائمة جانبية بمجموعات، وصفحة «حسابي» بكروت الأرصدة وتابات (عام، تقويم العمل، سجل الحضور، مفردات المرتب). على الموبايل (تطبيق): هيدر بروفايل وشريط سفلي (الجدول، لوحة المعلومات، الموظفون، القائمة) وزرار + للإضافة السريعة.
- **حسابي:** تابات: عام (الطلبات بفلاتر)، تقويم العمل (شهر بشهر بحالة كل يوم ومكان الحضور، مع طلب تغيير وردية وورديات إضافية)، سجل الحضور (يوم بيوم مع زرار «طلب تعديل»)، المرتبات (جدول شهري)، مفردات الرواتب (كروت الشهور وكشف المرتب وتحميل PDF).
- **صرف المرتبات:** بعد نهاية الشهر المدير بيسجّل الصرف من صفحة المالية (لكل موظف أو «إتمام عملية الدفع» للكل)، فالكشف بيتقفل بأرقامه وقت الصرف ويظهر عند الموظف «مدفوع»، ومبيتقبلش بنود جديدة على الشهر ده. إلغاء الصرف للمدير فقط.
- **الموظفون:** كروت بحالة اليوم (حضر / متأخر / غائب / إجازة)، وفلاتر (الدور، القسم، المنصب، المكان، الحالة، بحث)، وتابات لطلبات الحسابات واستعادة كلمة المرور.
- **المالية:** جدول المرتبات الملوّن (أزرق للمستحقات، أخضر للإضافات، أحمر للخصومات) والمرتب بيتحسب يوم بيوم: كل يوم بيعدّي بيستحق فيه الموظف (الأساسي + البدلات) ÷ 30، ويتزود المكافآت والوقت الإضافي، ويتخصم التأخير والغياب والجزاءات والخصومات، والناتج «مستحق الدفع».
- **صفحة الحضور:** شريط أيام الأسبوع، وزرار «تسجيل الحضور» ثم «تسجيل الانصراف»، وبيظهر بعدهم وقت ومكان كل تسجيل. التسجيل بالوجه إجباري، وبالموقع لو فيه مواقع معرّفة.
- **مواقع العمل:** من «الإعدادات» تضيفي أكتر من موقع (اسم + إحداثيات + نطاق بالمتر)، ومن «الموظفون ← تعديل» تحددي المواقع المسموحة لكل موظف. موقع العمل القديم بيتنقل تلقائياً كأول موقع باسم «الإدارة».
- **إنشاء حساب:** زرار في صفحة الدخول. الحساب بيتعمل كموظف بدون صلاحيات وبيستنى موافقة المدير (أو من عنده صلاحية «إضافة وتعديل الموظفين») من صفحة الموظفين. ممكن تقفلي الخاصية من الإعدادات.
- **نسيت كلمة المرور:** الموظف بيبعت طلب بإسم المستخدم، وبيوصل إشعار للمدير، والمدير بيضغط «إنشاء كلمة مؤقتة» وبيسلّمها للموظف، والنظام بيطلب منه يغيّرها عند أول دخول. (مفيش إيميل ولا SMS، فمفيش حاجة تتبعت برّه النظام.)
- **أنواع الحسابات:** مدير (كل الصلاحيات) أو موظف (الصلاحيات من صفحة «الصلاحيات»). المدير بس هو اللي ينشئ مدير آخر أو يغيّر نوع حساب من «تعديل» في صفحة الموظفين، ومدير الموارد العادي مايقدرش يلمس حسابات المديرين.
- **الإعدادات (بشكل الشاشات المرجعية):** من القائمة الجانبية ← الإعدادات: شركة (مكاتب وأماكن العمل + الأقسام والدرجات والمناصب...)، الحضور (مواعيد العمل، سياسات الجزاءات = شرائح التأخير، الوقت الإضافي...)، المالية (خيارات التكوين المسبق للراتب، البدلات، الخصومات...)، المستندات، القواعد، وإعدادات متنوعة. المكاتب والشرائح ومعاملات الخصم والوقت الإضافي والإعدادات العامة شغالة على المحرك الفعلي؛ باقي القوائم بتتخزن في جدول `config_items`.
- **صفحات الموظفين (بشكل الشاشة المرجعية):** تابات علوية (الموظفون، طلبات الحسابات، استعادة كلمة المرور، مجموعات العمل، فرق العمل، إجراءات الموظفين، مستندات الموظفين، الهيكل التنظيمي، سجل النقل، تغييرات المسمى الوظيفي، سجل الإيقاف، الإيقافات المعلقة)، فلاتر متعددة وقوالب فلاتر محفوظة، عرض كروت/جدول، وقائمة ⋯ لكل موظف (كلمة مرور مؤقتة، تحويل، تدقيق، تاريخ المكتب، إيقاف، إزالة، الصلاحيات). أضفنا حقلَي الجنسية والمدير المباشر للموظف.
- كل ده محفوظ في PostgreSQL، والجداول والأعمدة الجديدة بتتضاف تلقائياً على القاعدة القديمة من غير ما تتمسح بياناتك.

## متغيرات البيئة
| المتغير | المعنى |
|---|---|
| `DATABASE_URL` | **مطلوب.** رابط قاعدة PostgreSQL (من غير `&channel_binding=require`) |
| `ADMIN_PASSWORD` | كلمة مرور المدير في أول تشغيل فقط |
| `RESET_ADMIN_PASSWORD` | طوارئ: لو المدير الوحيد نسي كلمة المرور، حطيه وأعيدي التشغيل (بيعيّن كلمة مؤقتة لحساب `admin`)، وبعد الدخول شيليه |
| `JWT_SECRET` | اختياري؛ لو مش موجود بيتولّد ويتحفظ في القاعدة |
| `PORT` | المنفذ (3000) |

> تغيير `ADMIN_PASSWORD` بعد إنشاء الحساب مش بيغيّر كلمة المرور؛ غيّريها من داخل الموقع.

## تشغيل محلي
```bash
npm install
export DATABASE_URL="postgresql://user:pass@host/dbname?sslmode=require"
npm start
```
الكاميرا وGPS بتشتغل بس على `https://` أو `localhost`.

## النشر (Suga أو Render)
Docker من GitHub: المنفذ `3000`، والمتغيرات من تبويب Environment Variables (مش Build Arguments).
المسار `/healthz` بيرد `ok` من غير ما يلمس القاعدة.
